## UI模块
UI模块是MiteEngine引擎的用户界面系统，采用抽象后端设计支持多种UI框架（目前仅实现Dear Imgui后端）集成，通过事件驱动机制实现界面与引擎核心的深度交互。

### UI核心系统架构
UISystem模块是MiteEngine引擎的UI系统核心管理器，负责协调UI生命周期、事件处理、面板管理和渲染集成。该模块采用单例模式设计，通过依赖注入管理UI后端、样式系统和面板组件，为编辑器和运行时提供统一的UI管理接口。

ImGuiStyleAdapter模块负责将引擎样式系统与ImGui样式系统进行桥接
```cpp
void MapUIStyleToImGui(const std::shared_ptr<UIStyle>& uiStyle) {
    // 重置到默认样式
    ImGui::StyleColorsDark();
    
    // 映射各类属性
    MapColorProperties(uiStyle);
    MapEnumProperties(uiStyle);
    MapSizeProperties(uiStyle);
    MapBorderProperties(uiStyle);
    MapSpacingProperties(uiStyle);
}

void MapColorProperties(const std::shared_ptr<UIStyle>& uiStyle) {
    for (const auto& [propertyName, colorIndex] : m_ColorMappings) {
        if (uiStyle->HasProperty(propertyName)) {
            try {
                glm::vec4 color = uiStyle->GetProperty<glm::vec4>(propertyName);
                SetImGuiColor(colorIndex, color);
            } catch (const std::exception& e) {
                m_Logger->warn("Failed to map color property {}: {}", propertyName, e.what());
            }
        }
    }
}
````

```cpp
template<typename T>
void RenderProperty() {
    static_assert(std::is_base_of<Component, T>::value, "T Must be derived from component");
    if (!m_SelectedNode) return;
    
    // 查询到组件，创建属性，执行渲染操作
    if (m_SceneRegistry.HasComponent<T>(m_SelectedNode->GetEntity())) {
        T& component = m_SceneRegistry.GetComponent<T>(m_SelectedNode->GetEntity());
        PropertyTable<T> property(component);
        property.RenderTable(m_Renderer);
    }
}
````

```cpp
void UpdatePanelBorder(const glm::vec2& newPos, const glm::vec2& newSize) {
    if (newPos != m_PanelPos) { 
        m_PanelPos = newPos;    // 更新Panel位置
    }
    if (newSize != m_PanelSize) {
        m_PanelSize = newSize;  // 更新Panel尺寸
        // 发布Resize事件，Pipeline和SceneView接收事件后调整FBO尺寸与相机宽高比
        EventBus::Publish<ViewportResizeEvent>(ViewportResizeEvent(m_PanelSize));
    }
}
````
